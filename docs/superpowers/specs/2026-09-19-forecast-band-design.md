# 预测区间（预测带）与"以实际为准"措辞设计

日期：2026-09-19 ｜ 状态：实施中 ｜ 关联 task_plan Phase 49 第 21 项

## 背景

预测为纯线性趋势外推（不上季节性模型，经评估：容量规划用途下周内周期均值≈0、月度周期数据跨度不足、过拟合风险大于收益——决策记录见 findings.md 同日条目）。单线预测在负载摆动环境下会与实际值偏离，被读成"预测不准"。本设计不改预测模型，只做两件事：把不确定性以**预测带**形式呈现；客户文案统一为一句大白话，不出现任何统计术语。

## 口径

### 数学（后端 `forecast_series`）

- 在既有 OLS（`_linear_regression`，x 单位=天）基础上计算残差：`s = sqrt(SSres/(n-2))`（字节）。
- 预测区间半宽（95%，小样本用 t 分布修正）：`hw(t) = z·s·sqrt(1 + 1/n + ((x_now + t − x̄)² / Sxx))`；`z` 按 df=n−2 查 t 分布表（df≥30 取 1.96）。
- 对外暴露两个线性近似参数（前端按天外推绘图，与未来预测线同构）：
  - `band_half_width_now = hw(0)`（字节）
  - `band_half_width_per_day = z·s / sqrt(Sxx)`（字节/天；线性近似对 `hw(t)` 略保守偏宽，方向安全）
- 生效条件：`n >= 3` 且 `Sxx > 0`；否则两字段为 `None`。`s = 0`（完美直线）时两字段为 `0.0`。
- 新增字段挂在 `ForecastResult`（`asdict` 直通 report JSON），`api/models.py` 的 `ForecastModel` 增加对应 Optional 字段；dashboard 的 risk_clusters 透传不涉及带宽（列表只展示耗尽天数，不加宽契约）。

### 前端呈现

- `ClusterCapacityChart`：在"未来预测"区加"预测上限/预测下限"两条虚线（浅灰，随 `hw(t) = half_width_now + half_width_per_day × t` 展开，下限截 0）；多集群聚合时带宽求和（保守）。`band` 参数缺失或宽度为 0 时不画线。
- 图表下方固定一行说明（muted 小字）：「预测值可能会有偏差，以实际为准」。
- `ReportsPage` 预测行区域加同一句说明。仪表盘经 ClusterCapacityChart 自动获得带宽与说明。
- **措辞硬约束**：面向客户的文案不出现 R²、置信区间、标准差、拟合度等术语；只使用「预测值可能会有偏差，以实际为准」与「预测上限/预测下限」。

### 导出（Word/Excel）

- Word 末尾声明句扩为：「声明：本报告基于平台采集容量数据自动生成，预测结果基于历史增长趋势推算，预测值可能会有偏差，仅供参考，请以实际使用情况为准。」
- Excel 汇总口径区补同句声明（当前 Excel 无声明行）。
- Word/Excel 图表不画预测带（导出图仅历史趋势），不确定性由声明句承载。

## 测试计划

- 后端单测（`test_v2_reports.py`）：带噪声的合成线性数据 → 两个带宽字段 >0 且近期实际值大多落入带内；完美直线 → 0.0；n=2 → None；API 序列化（test_v2_reports_api.py FakeService 透传 + 模型含新字段）。
- 前端 vitest：图表 option 含"预测上限/预测下限"系列且数值符合 hw 公式；说明文案存在；band 缺失时不渲染带线。
- .3：全量回归 + 构建 + 健康检查 + `/api/reports/latest` 冒烟确认新字段；页面冒烟看图表带线与说明文案。

## 回滚

- 字段全部为 Optional 增量，前端渲染条件化；单提交独立回滚即可，无数据/结构变更。
