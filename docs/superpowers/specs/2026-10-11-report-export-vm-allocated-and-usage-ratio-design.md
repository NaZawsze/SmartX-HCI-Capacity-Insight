# 报表导出增强设计：虚拟机「分配空间」与「使用率」全量落位 —— Phase 74

- 状态：**设计定稿（2026-10-11），实施中**。
- 来源：2026-10-11 用户需求——「还想要在 excel 里的所有增长里，添加一列的虚拟机分配空间，这个分配空间的意思是这个虚拟机分了 40G 磁盘，现在使用了 30G 这个意思」，并确认采纳建议 3 方案 B（同时落位「分配空间」与「使用率」，并在新建 VM 表和 Word 报表中一并统一）。
- 数据现状：系统 SQLite `vm_volumes` 表在采集时已写入每个卷的 `size_bytes`（虚拟磁盘供给上限）与 `used_bytes`（实际占用），数据完全齐备，零外部依赖。

## 2. 字段口径与计算规则

1. **虚拟机分配空间（Allocated / Provisioned Disk Size）**：
   - 来源：`SUM(vm_volumes.size_bytes)` WHERE `(tower_id, cluster_id, vm_id)`。
   - 格式：`_xlsx_bytes_label(allocated)`（例如 `40.00 GiB`、`500.00 GiB`、`1.00 TiB`）。
   - 缺失/为 0：显示 `-`。
2. **虚拟机当前容量（Current Used Capacity）**：
   - 来源：Prometheus 实时采样 / 预测起点 `current`（即实际已使用容量，例如 `30.00 GiB`）。
   - 格式：`_xlsx_bytes_label(current)`。
3. **虚拟机使用率（Usage Ratio）**：
   - 计算：`current / allocated`（当 `allocated > 0` 时；例如 `30 / 40 = 75.00%`）。
   - 格式：`_percent_label(ratio)`（例如 `75.00%`）。
   - 缺失/为 0：当 `allocated == 0` 或缺失时，显示 `-`。
   - 超额：若因特殊情况 `current > allocated`，正常展示（如 `102.50%`），不强行截断。
